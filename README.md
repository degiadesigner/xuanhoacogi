# Xuân Hòa Có Gì - Cẩm Nang Ẩm Thực & Đặt Món Xuân Hòa

Website chính thức giới thiệu, khám phá và đặt món ẩm thực tại phường Xuân Hòa, TP. Phúc Yên, Vĩnh Phúc (Đại học Sư phạm Hà Nội 2 - ĐHSP2).

## Tính năng nổi bật
- **75 quán ăn & nhà hàng thực tế**: Đầy đủ địa chỉ, hotline, giờ mở cửa, menu và giá tiền.
- **Biển hiệu Typography tối giản & sang trọng**: Thiết kế đồng bộ, cân đối, chuẩn sang trọng hiện đại.
- **Menu chuẩn hóa hình ảnh ẩm thực**: Hình ảnh món ăn chụp chuẩn, bắt mắt, chân thực.
- **Tìm kiếm thông minh & Quay chọn món/chọn quán**: Phục vụ nhu cầu ăn uống hàng ngày của sinh viên và người dân.
- **Tối ưu di động & Desktop**: Giao diện Responsive siêu nhanh, mượt mà.

---

## Hướng dẫn cài đặt & chạy thử (Development)

```bash
# 1. Cài đặt thư viện dependencies
npm install

# 2. Khởi chạy máy chủ phát triển
npm run dev
```

---

## Hướng dẫn Build triển khai (Production Deploy)

```bash
# Build dự án ra thư mục dist/
npm run build

# Xem thử bản build production
npm run preview
```

Sau khi chạy `npm run build`, toàn bộ mã nguồn web hoàn chỉnh đã được đóng gói trong thư mục `dist/`, sẵn sàng upload lên:
- **GitHub Pages**
- **Vercel** / **Netlify**
- **Hosting cPanel** / **VPS Nginx** / **Apache**
